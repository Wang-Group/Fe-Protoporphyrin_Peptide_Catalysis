# ESM-2 Conditional Peptide Generation for High TON

This folder contains a complete workflow to:

1. Parse peptide sequences and TON values from `Machine_Learning/data_all.xlsx`.
2. Train a TON regressor on top of ESM-2 embeddings.
3. Generate new peptide sequences conditioned toward high TON.
4. Test key logic with `pytest`.
5. Train a conditional LoRA model with TON binning and sample from TON-conditioned bins.

The default model is `facebook/esm2_t12_35M_UR50D` (fast and GPU-friendly). You can switch to larger ESM-2 checkpoints for stronger modeling.

## 3) Train TON regressor

```powershell
python scripts/train_regressor.py `
  --excel-path ..\data_all.xlsx `
  --sheet-name batch1 `
  --output-dir artifacts\run1 `
  --device auto
```

Main artifacts:

- `artifacts/run1/ton_regressor.pt`
- `artifacts/run1/dataset_splits.csv`
- `artifacts/run1/training_history.csv`
- `artifacts/run1/metrics.json`

## 4) Generate high-TON candidate sequences

```powershell
python scripts/generate_sequences.py `
  --excel-path ..\data_all.xlsx `
  --checkpoint artifacts\run1\ton_regressor.pt `
  --output-csv artifacts\run1\generated_sequences.csv `
  --num-sequences 30 `
  --num-steps 40 `
  --top-k 8 `
  --require-aa K `
  --high-ton-quantile 0.9
```

Notes:

- If `--target-ton` is omitted, the script uses the dataset quantile from `--high-ton-quantile`.
- Sequences are generated by iterative masked mutation guided by ESM-2 likelihood and predicted TON.

## 5) Evaluate trained regressor

```powershell
python scripts/evaluate_regressor.py `
  --excel-path ..\data_all.xlsx `
  --checkpoint artifacts\run1\ton_regressor.pt `
  --split-csv artifacts\run1\dataset_splits.csv `
  --output-csv artifacts\run1\predictions.csv
```


The tests focus on data parsing/splitting, objective scoring, and generation core behavior.

## 7) Conditional LoRA + TON binning

Train conditional model:

```powershell
python scripts/train_conditional_lora.py `
  --excel-path ..\data_all.xlsx `
  --sheet-name batch1 `
  --aggregate none `
  --num-bins 3 `
  --output-dir artifacts\cond_lora_run1 `
  --device auto
```

Generate from high-TON bin with a required residue:

```powershell
python scripts/generate_conditional_lora.py `
  --run-dir artifacts\cond_lora_run1 `
  --excel-path ..\data_all.xlsx `
  --num-sequences 10 `
  --target-ton 24 `
  --require-aa K `
  --output-csv artifacts\cond_lora_run1\generated_conditional.csv `
  --device auto
```

Evaluate conditional model by pseudo-log-likelihood:

```powershell
python scripts/evaluate_conditional_lora.py `
  --run-dir artifacts\cond_lora_run1 `
  --output-csv artifacts\cond_lora_run1\conditional_eval.csv `
  --device auto
```
